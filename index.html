// antes de comprar

Seu notebook é compatível?

Siga estes passos rápidos. Em caso de dúvida, pergunte ao Bit.

  1. Descubra o modelo exato — etiqueta embaixo do notebook ou em Configurações → Sistema → Sobre.
  2. Veja o tipo de memória — no Windows, Gerenciador de Tarefas → Desempenho → Memória mostra DDR4 ou DDR5.
  3. Confira o slot de SSD — procure no manual por “M.2 NVMe” ou “SATA 2,5”.
  4. Verifique se a RAM é soldada — alguns modelos finos não permitem troca de memória.
